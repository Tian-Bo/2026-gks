# AI 一键生成营销活动

本仓库用于说明贵客松 48 小时内新增的「AI 对话生成营销活动」模块。

## 作品边界

**本次新增**：用户通过 AI 对话描述活动需求，系统生成活动草稿，并进入预览。

**赛前已有**：自研 SaaS「裂变快」的登录鉴权、权限、数据库、活动渲染内核和基础设施。这些能力只提供运行环境，不属于本次参赛成果。

**不在本次范围内**：重做账号、权限、数据库、活动渲染引擎、通用编辑器、模板市场和历史活动管理。

## 方案

```text
活动需求 -> AI 对话生成模块（本次新增） -> 活动草稿 -> 裂变快预览（赛前已有）
```

AI 模块负责需求补全、Prompt 编排和活动配置生成；裂变快只负责保存已确认的配置和渲染预览页面。

## 接口

| 接口 | 输入 | 输出 | 归属 |
| --- | --- | --- | --- |
| `生成活动草稿` | 对话消息、当前需求 | 活动草稿、待补充项 | 本次新增 |
| `确认活动草稿` | 用户确认后的草稿 | 活动配置标识 | 新增模块转换，底座保存 |
| `活动预览` | 活动配置标识 | 预览页面 | 赛前底座 |

## 字段映射

| 用户需求 | 活动草稿字段 |
| --- | --- |
| 活动名称 | `name` |
| 活动目标 | `marketing.objective` |
| 目标人群 | `targeting.audience` |
| 活动时间 | `schedule.startAt`、`schedule.endAt` |
| 参与方式 | `mechanism.type` |
| 奖励权益 | `rewards` |
| 品牌文案 | `content.headline`、`content.description` |
